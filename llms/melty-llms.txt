## APIs

There is no Melty API. Melty publishes no developer portal, no OpenAPI, AsyncAPI, GraphQL SDL,
Postman collection, MCP server or A2A agent card. The only HTTP APIs associated with the company are
open-source servers you host yourself:

- [Kisee](https://kisee.readthedocs.io/en/latest/): identity provider server. Exchanges a
  username/password pair for a JWT. Self-hosted; default port 8140. `pip install kisee`.
- [Pasee](https://pasee.readthedocs.io/en/latest/): identity management server layering groups and
  multiple identity backends over one or more Kisee instances. Serves a JSON-Home document at `/`.
  Self-hosted; default port 8150. `pip install pasee`.

Neither is a Melty-operated endpoint. Both were last released in 2021.
